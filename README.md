# Web Scraper

A simple Python web scraper that extracts news titles and links from a website and saves them to a CSV file.

## Features

- Scrapes webpage data
- Extracts titles and links
- Saves results to CSV
- Supports command-line arguments

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

python -m pip install -r requirements.txt
